# 像素级复刻可行性与差距实测

> 问题：现在这套资产能不能做到「像素级复刻」？答案分两层：**结构/颜色/图标可以做到接近逐像素；数学意义上的全等做不到**（字体与系统层差异）。下面是实测数据与差距清单。

## 1. 实测方法

| 项 | 值 |
|---|---|
| 官方来源 | `analysis/reference/real-screens/`（Android 14 模拟器，1080×2400 @420dpi = **411.4×914.3dp**） |
| 官方有效内容区 | 去掉顶部状态栏 24dp（63px）与底部三键导航 48dp（126px）→ **411×842dp**（1080×2211px） |
| 复刻来源 | uni-app H5 重建后，用 CDP 设备模拟 **411×842 CSS px、DPR 2.627737**（= 1080×2213px，按 2211 对齐） |
| 对齐 | 裁掉官方状态栏/导航栏，两边缩放到 1080×2211 |
| 指标 | 灰度 + 3px 高斯模糊（抑制字体抗锯齿）后的**平均绝对差**（0-255）与**差异>16 的像素占比**；另按 header/body/tabbar 分区 |
| 脚本 | `tools/pixel-diff.py`（可复用）；输出在本目录 |

## 2. 实测结果（同一视口、同一内容区）

| 页面 | 模糊后平均差 | 差异>16 像素占比 | header | body | tabbar | 结论 |
|---|---|---|---|---|---|---|
| 首页 | 29.10 | 30.4% | 11.5 | 36.8 | 1.1 | 结构已对齐；差异主要来自**官方空态 vs 复刻演示数据** |
| 班次 | 4.20 | 3.4% | 10.8 | 3.2 | 0.8 | 两边都是空态 → 全屏 3.4%，接近像素级 |
| 提醒 | 13.87 | 16.5% | 31.5 | 11.7 | 0.8 | header 差异大：官方有权限提示条/开关，复刻布局不同 |
| 统计 | 16.06 | 14.0% | 16.1 | 17.5 | 5.2 | 官方空数据 vs 复刻演示图表 |
| 我的 | 11.18 | 14.2% | 12.1 | 11.8 | 4.8 | 结构一致；字体/行高/图标细节有差 |

**最关键的一行：班次页两边都是空态，全屏只有 3.4% 像素不同，底部 Tab 栏分区差异 0.8。** 这说明「布局、间距、颜色、图标字体」已经基本做到像素级；当前大差异主要不是能力问题，而是**数据状态/字体/局部组件**没对齐。

对照板：`board-411dp.png`（5 屏左右对照）、`compare-*-411dp.png`、`diff-*.png`（差异热图）。

## 3. 要真正逐像素，差的 6 件事

| # | 差距 | 影响 | 能否解决 |
|---|---|---|---|
| 1 | **数据状态**：官方截图是全新安装空态，复刻是演示数据 | 首页/统计/我的差异 30%/14%/14% | ✅ 用同一份空数据重渲染即可；或反过来给官方导入同一份排班 |
| 2 | **字体**：Android 用 Noto Sans CJK/思源黑体，macOS/浏览器用苹方 | 所有文字区域（尤其 header 标题、正文）几十个像素级差异 | ⚠️ 部分可解：H5 内嵌 Noto Sans SC（woff2）并统一 font-family/字重；抗锯齿与 hinting 仍不同，**无法 100%** |
| 3 | **系统层**：状态栏 24dp、三键/手势导航栏 48dp、状态栏图标/时间 | 整屏上下各一条 | ⚠️ 可模拟（H5 画假状态栏/导航栏），但系统图标需自己绘制；真机逐像素无意义 |
| 4 | **局部组件差异**：提醒页权限条、公告条、空态插画、开关/圆角/阴影/分割线 | header 31.5、body 11-17 | ✅ 逐屏按 `diff-*.png` 热图校准（代码里有精确 dp，可 1-2dp 内收敛） |
| 5 | **运行时效果**：水波纹、页面过渡、滚动条、Material elevation 阴影、弹窗动画 | 静态截图外 | ⚠️ CSS 可近似，无法与 Compose 渲染完全相同 |
| 6 | **平台专属**：Glance 桌面小组件、系统权限弹窗、日期/滚轮选择器原生组件、状态栏下拉 | 无法在 H5 复刻 | ❌ 只能做到视觉近似 |

## 4. 结论

- **可以做到「视觉 1:1 / 同屏截图肉眼难辨」**：布局、颜色、圆角、图标字体、Tab 栏已经对齐（空态页 3.4%、tabbar 0.8）。
- **做不到数学意义的逐像素全等**：字体渲染（Android Noto vs macOS 苹方）、系统栏、Compose 阴影/水波纹/动画属于平台层差异；把 Noto Sans SC 内嵌可以把差距压到很小，但仍非 0。
- 若目标是「发给别人对比截图看不出差别」：完全可行，按 §3 的 1/4 两项做逐屏校准即可（预期空态页差异降到 <2%）。

## 5. 下一步（可按顺序执行）

1. 复刻端切换「空数据/演示数据」两种状态，与官方截图一一对应；
2. H5 内嵌 Noto Sans SC（400/500/700）并统一字体栈；
3. 增加可切换的模拟状态栏/导航栏（默认关，截图对比时开）；
4. 用 `tools/pixel-diff.py` + `diff-*.png` 逐屏修 header 高度、间距、颜色；
5. 补暗色官方截图（现只有首页/我的两张），再做暗色 diff。
