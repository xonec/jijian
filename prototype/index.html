极简排班 UI 复刻

基于 APK cn.jianyun.workplan 3.5.0 反编译还原。
配色 / 字号 / 图标 / 文案均取自安装包本体。

界面

主题

一周开始日（APK 可配置，默认周一）

强调色（3.5.0 固定 #55BB8A，无换肤入口）

可交互

· 点日期选择当天，日历下方显示班次/备注
· 下方色板仅用于演示：APK 内 230 中国色实际用于「班次颜色 / 小组件配色」
· 点「开启排班」进入排班模式（底部操作面板）
· 点右上角 3 个按钮：去广告 / 项目管理 / 显示配置
· 点「9月」打开月份选择；提醒卡片开关可切换
