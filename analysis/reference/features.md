### 2.3 实测界面暴露出的功能（来自 §3 截图/视频，均需以代码复核）
- 首页月历：公历 + 农历 + 节假日显示、班次徽章（名称/开始时间/休息全天）、选中日高亮、「调班」标记（见 README §4 第 9 条存疑）、左右滑动/上月下月切换。
- 日历显示设置（底部弹层）：一周开始日（周一/周日）、显示中国农历、显示中国节假日、显示上班时间、显示备注、显示统计指标、显示分割线、保存。
- 多排班项目：「选择排班项目」弹层、默认项目、当前项目、管理、共 N 条记录。
- 班次管理：班次/轮班两种视角、添加班次、班次排序；添加班次表单含 普通班次/组合班次、班次名称、是否全天、开始/结束时间（支持「次日」跨天，如 20:00~次日08:00）、班次颜色、样式预览。
- 自定义排班操作条：自定义排班 / 周期轮班；清除、上一天、下一天、关闭；点选班次徽章上排。
- 提醒：普通提醒、当天/第二天（提前一天）、下次提醒时间（后天 07:55 提醒）、单条开关；日历授权（操作/查询）；「关于班次提醒?」「检查班次提醒是否生效?」。
- 统计：日期区间（起止日期）、环形饼图、班次次数与占比、空态「暂无数据」；3.5.0 新增时长统计/时长占比饼图/导出 Excel（见 §3 官方更新日志）。
- 小组件：描述与更新日志多次提及；代码有独立 widget 配置页；**无截图**。
- 我的：第 5 个底部 tab（`ScheduleMainViewKt.java:429`），含设置类入口（`views/setting/ScheduleSettingViewKt.java`）。
